# Building from source

The source code goes up with the beta. Until then, this repository has the guide, and the releases have everything you need to play.

## Steps

1. **Eye colors:** `powershell -File tools\make_ff.ps1`
   - Builds `build\mod.ff` with [OpenAssetTools](https://github.com/Laupetin/OpenAssetTools)' Linker from your own copy of the game.
   - Set `OAT_BASE` and `BO2_GAME` if OpenAssetTools or the game aren't in their default folders.
   - The other steps need this file.
2. **Install the mod:** `install.bat`
   - Copies the mod to `%LOCALAPPDATA%\Plutonium\storage\t6\mods\zm_toybox` and packs `ui\` into `mod.iwd`.
   - It won't run while the game is open.
   - `install.bat global` and `install.bat unglobal` add and remove the global copy.
3. **ToyBox.exe:** `powershell -File tools\make_app.ps1`
   - Builds `dist\ToyBox.exe` with the .NET Framework 4 compiler that comes with Windows. Nothing to install.
   - Needs `remote\cloudflared.exe` (from `remote\get-cloudflared.bat`), signed by Cloudflare.
4. **A release:** `tools\make_release.ps1 [-InstallerUrl <url>] [-Test]`
   - Builds ToyBox.exe, signs it when `TOYBOX_SIGN` is set, and writes winget manifests.
   - `-Test` runs the tests first.

## Checks and tests

- **Scripts:** `python -I tools\check_gsc.py --stock <decompiled T6 zombies scripts>` finds what would stop the mod from loading: missing functions, map-only calls from common scripts, too many arguments, a missing `;`.
- **App:** `tests\app\test_server.ps1` runs the app and host controls against a fake game.
- **Installer:** `tests\app\test_installer.ps1` installs, updates and uninstalls in a temp folder.
- Each test runs with one command and cleans up after itself.

## Extras

- **Friend page art:** `python tools/make_art.py <dump folders>` (Pillow and numpy) takes the perk icons, power-ups and weapon pictures from your own copy of the game. Its header has the OpenAssetTools commands. `remote/art` is checked in, so you only need this to change it.
- **Silent install:** `ToyBox.exe /S` installs with no window (for winget).

## Where things are

| Path | What's there |
|---|---|
| `mod.json` | The name in the Mods menu |
| `scripts/zm/toybox.gsc` | Command input, built-in commands, stock tables |
| `scripts/zm/toybox_api.gsc` | The [mod API](mod-api.md) |
| `scripts/zm/toybox_remote.gsc` | The game side of the friend link |
| `scripts/zm/toybox_world.gsc`, `toybox_mods.gsc`, `toybox_fun.gsc`, `toybox_events.gsc` | The map, zombie and player modifiers, scares, and what runs over time |
| `scripts/zm/toybox_bot.gsc` | The simulated friend |
| `scripts/zm/toybox_eyes.gsc`, `zone_source/mod.zone`, `tools/t6_ff_patch.py` | Zombie eye colors |
| `scripts/zm/<map>/` | What only one map has (Brutus, Panzers, Jumping Jacks, ghosts, generators, staffs) |
| `scripts/zm/toybox_origins.gsc` | Which stock maps have each weapon, perk and power-up. Generated by `tools/make_origins.py` |
| `ui/t6/options.lua` | The Options menu with the TOY BOX tab |
| `app/` | ToyBox.exe: installer, tray app, friend page server, host controls |
| `remote/` | `page.html` (what friends see), plus the older PowerShell companion |
| `release/README.txt` | The player guide in the release |
| `tests/app/` | The tests, with `fake_game.ps1` standing in for the game |
| `tools/check_gsc.py` | The script checker. `.github/workflows/check.yml` runs it on each push |

## About the eye colors

Orange is the game's own eye. Red and blue are the Mob of the Dead and Buried eyes, copied so they work on every map. Purple is the orange eye recolored. White is the orange eye's elements moved into another stock eye's slot, since each copy needs its own source. `tools/t6_fx_read.py` reads effects out of a fastfile.
