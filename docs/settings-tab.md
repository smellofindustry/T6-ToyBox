# The TOY BOX settings tab

In a Toy Box match or the main menu: **Options > Settings > TOY BOX**.

| Setting | What it does |
|---|---|
| **Friend controller** | On or off. When off, friends' buttons do nothing |
| **Show link on screen** | Shows the friend link again |
| **Copy link** | Copies it again |
| **Zombie eyes** | The map's own, orange, red, blue or purple, for everyone |
| **Random events** | Off, or a random event every 1, 2, 3 or 5 rounds |
| **Simulate a friend** | See [Playing alone](play-alone.md) |
| **Intensity** | How busy the simulated friend is |
| **Compatibility mode** | Lets Toy Box use what other mods add ([more](mod-api.md)) |

Under them: your friend link, whether it works from anywhere or only at home, and who's on right now.

## Good to know

- Settings are saved for your next game.
- In a solo game the menu pauses the match. Changes kick in when you go back.
