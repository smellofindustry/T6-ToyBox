# Match stats and contests

Toy Box keeps score for everyone.

- **Players:** kills, headshots, downs, revives.
- **Friends:** zombies sent, how many got killed, downs caused, bounties set, won and lost.

## Contest ideas

- **Who can take down the host?** Friends get 5 rounds each. Most downs caused wins.
- **Bounty hunter.** Friends set bounties on each other's turns. Most bounties won wins.
- **Survive the troll.** Everyone plays solo on the same map with a [simulated friend](play-alone.md) on troll, wild. Highest round wins.

## Getting the numbers

- **During the match:** friends see **Match stats** on their page.
- **After the match:** [Host controls](host-controls.md) > **Match history**.
  - **CSV:** one row per player and per friend, ready for a spreadsheet.
  - **JSON:** everything, with every command and the game's answer.
- Friends can download matches played on the current link from their page too.
- The newest 100 matches are kept. Teddy bear > **Open match history folder** shows the files.
