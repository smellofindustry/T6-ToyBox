# The teddy bear menu

Toy Box lives by the clock as a teddy bear.

Don't see it? Click the **^** arrow next to the clock.

## Click the bear for

| Button | What it does |
|---|---|
| **Copy friend link** | Copies the link for your friends |
| **Open friend link** | Opens it, so you see what they see |
| **Show link in game** | Puts the link back on your screen |
| **Pause friends** | Their buttons stop until you switch them back on |
| **New link** | Makes a new link. The old one stops working right away |
| **Host controls** | Kick, ban, limits, what friends can use ([more](host-controls.md)) |
| **Start with Windows** | On by default. Click to switch it off |
| **Open match history folder** | Your saved matches |
| **Open log** | For bug reports |

## Good to know

- The first line of the menu is the version. Put it in bug reports.
- Toy Box starts with Windows and does nothing until you play.
